# EVEN — Android app

EVEN is an offline-first shared-expense app. This repository contains the first buildable product foundation: the visual shell, local SQLite schema, group and expense creation, integer-safe split calculations, debt simplification, tests, and a GitHub Actions APK build.

## Current milestone

Included:
- Minimal Material 3 interface with Home, Activity, Insights and Settings tabs.
- Local SQLite database with groups, expenses, shares, settlements, recurring-expense, comments and activity tables.
- Create groups and record expenses locally.
- Equal split calculation using integer minor units (paise), with exact remainder handling.
- Greedy debt simplification engine.
- Automated tests for split correctness and debt simplification.
- GitHub Actions workflow that generates an Android platform project, tests the app and uploads a release APK.

Not yet implemented: multi-payer entry UI, arbitrary custom split UI, friends/private ledger UI, cloud authentication/sync, OCR, recurring scheduling, charts, CSV/JSON export, push notifications, biometric lock and payment-provider integrations. The database schema anticipates several of these, but a schema table is not a completed feature. These will be built and tested in later milestones.

## Build an APK using GitHub (recommended for Windows)

1. Create a new **public or private** GitHub repository named `even-android`.
2. Extract this ZIP on your computer.
3. Open the extracted `even-android` folder. The files inside it should include `pubspec.yaml`, `lib`, `test`, `.github` and `README.md`.
4. Upload the contents of that folder to the root of your GitHub repository. Do not upload an extra enclosing folder level.
5. On GitHub, open **Actions**. If asked, enable GitHub Actions for the repository.
6. Select **Build EVEN Android APK** on the left.
7. Click **Run workflow**, select `main`, then click the green **Run workflow** button.
8. Wait for the run to finish. Open the successful run and scroll to **Artifacts**.
9. Download `even-android-release`, extract it, and install `app-release.apk` on your Android phone. You may need to allow installation from your browser or file manager.

A push to `main` also triggers the workflow automatically.

## Build locally (optional)

Install the Flutter stable SDK and Android SDK, then run:

```bash
flutter create --platforms=android --org com.even --project-name app /tmp/even-platform
cp -R /tmp/even-platform/android ./android
# Change android:label in android/app/src/main/AndroidManifest.xml to EVEN
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

On Windows PowerShell, replace the `cp` line with:

```powershell
Copy-Item -Recurse -Force /tmp/even-platform/android ./android
```

## Product and engineering notes

- Package/application ID generated by the workflow: `com.even.app`.
- Currency values are stored as integer minor units. Never store money as floating-point values.
- The first version defaults to INR and a local-only experience. No account or backend credentials are required to try it.
- Cloud collaboration requires a configured backend and security rules before it should be exposed to real users.
- Before public distribution, create a private Android signing key, store signing secrets in GitHub Actions secrets, and build a signed release. The current APK is suitable for internal testing, not a Play Store production release.
- EVEN is a working product name. Verify trademark, domain and app-store availability before public launch.
